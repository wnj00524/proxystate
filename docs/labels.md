# GitHub Labels

Labels used by the Proxy State repository and the `PState` project:

| Label | Meaning |
| --- | --- |
| `accessibility` | Barrier affecting people with disabilities. |
| `bug` | Something is not working. |
| `documentation` | Improvements or additions to documentation. |
| `duplicate` | A duplicate issue or pull request. |
| `enhancement` | New feature or request. |
| `framework` | Core runtime, ECS, rendering, or infrastructure work. |
| `good first issue` | Suitable for newcomers. |
| `help wanted` | Extra attention is needed. |
| `invalid` | The issue or request is not valid. |
| `question` | Further information is requested. |
| `wontfix` | The issue will not be worked on. |
